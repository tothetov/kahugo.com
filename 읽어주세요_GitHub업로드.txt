  KAHUGO — GitHub 저장소(tothetov/kahugo.com) 업로드용
════════════════════════════════════════════════
  [올리는 법]
   1. 이 ZIP 의 압축을 풉니다.
   2. github.com/tothetov/kahugo.com 에서
      「Add file」→「Upload files」를 누릅니다.
   3. 압축을 푼 폴더 안의 '내용물 전부'를 끌어다 놓습니다.
      (폴더 자체가 아니라, 그 안의 파일과 폴더들입니다)
   4. 아래 「Commit changes」를 누릅니다.

  [들어 있는 것]
   index.html · styles.css · data.js · book.js · app.js   ← 사이트 본체
   assets/                                                ← 이미지·로고
   admin/index.html                                       ← 관리자 페이지(단일 파일)
   functions/api/login.js · content.js                    ← 실시간 편집 서버
   _headers · _redirects                                  ← Cloudflare 설정
   kahugo-standalone.html                                 ← 폰에서 파일로 볼 때

  [올린 뒤 Cloudflare 에서 두 가지]
   ① 설정 → 환경 변수 및 암호 → ADMIN_PASSWORD 추가 (Secret)
   ② Storage & Databases → KV 네임스페이스 생성 → 바인딩 이름 KAHUGO_KV

  그다음 https://kahugo.com/admin/ 으로 들어가시면 됩니다.
